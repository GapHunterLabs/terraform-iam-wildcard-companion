# Privacy Policy — Terraform IAM Wildcard Companion

**Effective date:** 2026-09-01

Terraform IAM Wildcard Companion is a Gap Hunter Labs plugin for
IntelliJ Platform IDEs. This policy is short because the plugin's
design makes it short: there is nothing to disclose beyond what's
below.

## What this plugin collects

**Nothing.** This plugin does not collect, store, transmit, or sell
any data — no source code, no file contents, no file paths, no usage
analytics, no telemetry, no crash reports, no personally identifiable
information. Your open file's text is read only in memory for as long
as the IDE is open.

## Network access

**None.** This plugin makes zero network calls during normal
operation, and never connects to a real AWS account.

## Third parties

None. This plugin has no third-party SDKs, no analytics libraries, no
ad networks, no dependencies that phone home.

## Changes to this policy

If this ever changes, this file will be updated and the change will be
noted in the plugin's `CHANGELOG.md`.
